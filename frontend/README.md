# Workpulse Frontend

React + Vite + Tailwind CSS

## Setup

```bash
cd frontend
npm install
npm run dev
```

App runs at http://localhost:3000

## Login (dev mode)
Select any role from the dropdown — no password needed.

## Stack
- React 18
- Vite
- Tailwind CSS
- React Router v6
- Lucide React (icons)
